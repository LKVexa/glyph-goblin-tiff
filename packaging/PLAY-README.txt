GLYPH GOBLIN 0.4 - WINDOWS x64 PLAYER

Extract the entire Windows player ZIP into a new folder, then open Play.cmd or
GlyphGoblin.exe. The bundled TIFF image opens and computes automatically.
Use Open TIFF / GIF to execute another approved image. Results are saved in a
fresh Results folder as TIFF, GIF and detailed OCR evidence.

No Python, Tesseract, model installation, developer tools or internet connection
is needed to run this package. Keep all extracted files together. GitHub's
automatic Source code ZIP is developer source, not this ready-to-run release.

The visible glyphs contain arithmetic/Boolean programs. The black/white raster
contains the approved interpreter module. The desktop reads those pixels, runs
real local OCR and executes the recovered interpreter only after every OCR pass
agrees on expression structure. Ambiguous input is rejected, never guessed.
Agreement is not a guarantee against all OCR errors; inspect recognized text.

CPython, JA21 image preparation, the native OCR sensor, UI and image reader are
the external bootstrap environment. Computation is on the CPU, not optical
hardware. Original glyph pixels and interpreter bytes survive output refresh.

Do not resize or lossy-resave the carrier image. Retain the exact error if an
administrator's application-control policy blocks launch; do not disable it.
